## 文件能力与边界

- 16 KiB 二进制分块，256 KiB 接收写入确认窗口；发送和接收处理队列均有边界。
- 全文件长度和 SHA-256 一致、sink 关闭成功后才报告 complete；文件任务清空不能作为完成依据。
- 支持 picker 的浏览器向用户选定文件流式写入。无流式能力时，接收中和待保存 Blob 合计 64 MiB，超限在传输前拒绝。
- 内存保存模式等待上一文件保存或丢弃，再发送下一邀请，避免叠加弹窗和 Blob。
- 存储写入/提交失败只取消文件并显示原因，不破坏正常直连。取消只丢弃已在途的有界窗口；非法协议则关闭连接，并清除“已直连”状态。
- 暂停/继续只适用于当前连接；断线后重新选择文件重发，**不声称已有跨连接续传**。
