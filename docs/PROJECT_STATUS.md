## 核心实现

- 仅 RTCDataChannel 文件正文。没有 TURN、服务器上传/存储或 WS 文件代理；只承认实际 selected 非 relay candidate pair。
- 服务器签发 peer ID / 256-bit 恢复令牌；128-bit 随机邀请，未配对 15 分钟，最多两名成员。
- 配对后立即锁定双方，使用独立固定最长 12 小时会话；重连不延长，第三台不能替换退出成员。原成员离线席位预留 2 分钟，双方离开/预留结束后回收锁定房间。
- 双方人工核对 DTLS 指纹安全码，接收方同意后才允许文件字节。精确 Origin 与无 query WS 路径、嵌套白名单、大小/速率/总量限制。
- 16 KiB 分块、256 KiB 写入 ACK 窗口、发送背压/接收队列上限、增量 SHA-256、流式 sink / 全局 64 MiB Blob 回退池。
- 多文件队列、当前连接暂停/继续/取消、速度/ETA、配额/写入/关闭失败原因。回退模式保存/丢弃上一 Blob 后才发下一邀请。
- 实际 Zeydrop 工作台、原创 SVG/图标、深浅色/手机、二维码、隐私、键盘焦点、PWA 更新；本机白名单诊断最多 120 条，不导出 IP、身份、令牌、安全码或文件信息，不自动上传。
- 可重复构建覆盖客户端、服务端和部署输入；HTTPS/WSS、无特权 systemd、版本目录/配置失败恢复/回滚候选；GPL 来源和依赖声明。

## 限制与外部条件

CI 全部在同一主机且关闭 STUN，不证明公网 UDP 打洞成功率。OPFS 使用真实原生 writer，但 picker 选择由测试替代；不证明真实用户授权体验。WebKit UI 不是 Safari/iOS 文件传输；Firefox 未跑 1 GiB。所有浏览器的硬件/运营商矩阵仍待测。

暂停只保持当前连接；断线会取消文件，重连后需重新核对安全码并重新选择重发。无流式能力接收中/待保存 Blob 合计最多 64 MiB；会话最长 12 小时。不能把从零重发记为续传，不能宣传服务器总流量为零。

当前 Work 执行环境没有可操作的第二个真实网络设备、Safari/iOS 硬件、用户生产主机或已确认域名/证书。GitHub CI 可验证协议，无法代替这些验收。没有正式部署、Release 或稳定版合并；不承诺会话结束后继续运行，不创建定时任务。
